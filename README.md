# sheaveline

Lift department records for a passenger ropeway operation: the installation, the
haul rope and its tests, line geometry, capacity, weather holds, the daily
operating log, the inspection ladder, evacuation planning and the filings the
state tramway board asks for.

Measures are US customary, because that is what the drawings and the board's
forms use.

## Layout

    src/sheaveline/     the package
    tests/              the suite

## Running it

    pip install -e ".[dev]"
    pytest
